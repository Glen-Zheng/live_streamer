## Live Streamer

A end-to-end system that will fetch frames for your live stream, based on some web link and stream those frames live in a video to some host.

The host must be specified. Currently it is hardcoded.


./findpng2 -t 10 -m 50 -v log.txt -s 1 http://ece252-1.uwaterloo.ca/~yqhuang/lab4/
